# Bow Project Launcher

A central hub for discovering public PotterService and Bow projects hosted on GitHub.

Bow Project Launcher automatically scans public GitHub repositories and displays projects that contain an `index.html` file, making it easy for visitors to find websites, tools, trackers, collector projects, and other public creations.

---

## Live Website

https://launcher.potterservice.com

---

## What It Does

The launcher automatically:

* Scans public PotterService GitHub repositories
* Detects repositories containing an `index.html` file
* Displays project names and descriptions
* Shows last updated dates
* Provides direct links to:

  * Live GitHub Pages websites
  * GitHub repositories

This allows visitors to browse available projects without needing to search through GitHub manually.

## How It Works

The launcher uses the GitHub API to:

1. Retrieve public repositories from the PotterService account.
2. Check each repository for an `index.html` file.
3. Display qualifying projects automatically.
4. Generate links to both GitHub Pages and GitHub repositories.

No manual project list is required.
